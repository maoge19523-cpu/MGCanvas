# Pending Tests

The current release needs manual verification in these areas:




- Built-in speech scripts: with a 百炼 channel (model `qwen-tts`) or a 智谱 channel (model `cogtts`) an audio generation must work without writing any script, because the built-in one is matched by the interface address. 百炼 returns a temporary audio URL and must still play; 智谱 returns raw audio bytes and must not be mangled by text decoding. The 音色 field must reach the request, and generating audio for 方舟 must fail with a clear message rather than silence.

- Segment fades and track loop: a segment's own fade in/out must darken and silence that segment's start and end, its own audio included, while a transition on the same seam still plays. Turning 循环 on for the music track must make a track shorter than the film repeat until the film ends, and its fade-out must still be measured from the film's end.

- Composite timeline: the strip under the composite panel must size each clip by its real duration, mark a segment with a transition as a diamond and a hard cut as a bar, and jump back to the source clip on the canvas when clicked. Dragging a clip body sideways must reorder the segments and the composed film must follow that new order; dragging either edge must trim that clip's in or out point in proportion to the clip's width, without crossing the opposite bound; the existing 上移/下移 buttons and 入/出 fields must keep editing the same settings. Timeline dragging now commits on release instead of on every pointer move: while dragging a clip body the strip does not reorder live, and while dragging an edge the seconds do not change live — both must apply once the pointer is released, and dragging must no longer crash the interface.

- Style gallery covers: in the canvas left panel open 提示词库, click any style and use 「设为封面」 next to 复制提示词 to pick a local image for that style; the card must show it immediately and keep it after restarting the client. Generating an image right after picking a style must also set that style's cover automatically (a manually chosen cover wins). Only built-in styles expose the button.

- Built-in style gallery: the prompt library must list a built-in 风格馆 source with 94 original style descriptions under eight categories (真人写真、东方古风、现代影像、科幻幻想、自然氛围、暗黑废墟、巨物传说、二次元插画). Filtering by category, searching, and picking a card must fill the prompt box. It must work with no network access, and it must still appear for users who already had prompt sources saved before this build.

- ComfyUI live node progress: running a ComfyUI workflow node on the canvas must show the node currently executing plus its step percentage in the node header (for example 「运行中 · KSampler · 60%」), and the node name must change as execution advances. When the run finishes the progress must give way to the usual 成功 result and elapsed time. If progress never appears but the run still completes, the work is unaffected — report it so the WebSocket path can be checked.

- ComfyUI run history: on the 「ComfyUI 本地」page a 运行历史 section must appear under the workflow library. Running a ComfyUI workflow node on the canvas must add one record with its outcome, start time, duration and outputs (images shown as thumbnails); a failed run must show its error text; 删除 must drop one record and 清空 must drop all of them; records must survive restarting the client.

- Timeline drag crash: dragging a clip body sideways or either trim edge must never crash the interface on the packaged desktop build. If the interface does show the error card, it must show the raw React message, the component stack, and the console output captured before the crash; 重试 and 重新加载界面 must both recover.

- Bailian image-to-video: giving the video node a first-frame image must produce a clip that follows that frame, while a plain text run keeps the verified text-to-video shape. Both request shapes are already verified against the live API (the image-to-video task reached SUCCEEDED and returned a `video_url`), so what is left to confirm is the in-app path from a canvas image into the video node.

- 302.AI channel: it is reachable only through the machine's system proxy (direct connections to its overseas node time out), so adding a channel from the new `https://api.302.ai/v1` preset and pressing 「获取模型」 must come back with either the model list or the provider's own wording — a network timeout instead would mean the desktop HTTP layer does not follow the Windows proxy setting and needs its own handling. Chat and image generation through that channel must work without any call script, and video or audio must be checked against the provider's real shapes before any script is written for them.

- Bailian video sizes: the video call script must send one of the sizes the service accepts (1080*1920, 1920*1080, 1440*1440, 1632*1248, 1248*1632, 480*832, 832*480, 624*624) — the earlier values made every task fail with `InvalidParameter`, verified live, while `1920*1080` polled to SUCCEEDED with a `video_url`. Generating a video through a Bailian channel must therefore return a playable clip for each canvas ratio.

- Zhipu image sizes per model: the image call script must pick canvas sizes by model, because `glm-image` only accepts side lengths divisible by 32 — the CogView size for 16:9 (`1440x720`) is rejected with 1214 (verified live), while `1728x960` succeeds. Selecting `glm-image` as the channel image model must therefore still produce an image for every canvas ratio offered in the panel.

- Channel text endpoint: text generation through a channel model from the node prompt panel, the Config-node content panel, and node retry must post to `{base}/chat/completions` and stream the answer into the node as it arrives. Zhipu answers 404 on `/responses` (verified with a real key) and 200 on `/chat/completions`; a first chunk carrying only `role` must be skipped, and a `reasoning_content` field — which both Zhipu and DeepSeek return alongside the answer — must never leak into the node text. A provider that ignores streaming and answers with one JSON body must still fill the node, and the reasoning setting must be sent as the standard `reasoning_effort` field rather than the Responses-API `reasoning` object.

- Channel video body: a channel model without a matching call script must post the plain OpenAI videos shape — `model`, `prompt`, `seconds`, `size`, `input_reference[]` — with no `resolution_name` or `preset`; a strict compatible provider must accept the request, and the resolution chosen in the panel must still arrive as `size`.

- AI director whole-film hand-off: finishing 「一键生成整片」 must leave a composition node already wired underneath the generated film, so music and whole-film trimming need no manual node and connection, and must then show a review prompt repeating the requested duration and aspect plus how many spec-check problems the generation had.

- AI director whole-film packing density: the system prompt sent to the reasoning model must carry the concrete shot count for the requested duration — 10 seconds 2–3 shots, 12 seconds 3–4, 15 seconds 3–5 — together with the duration and aspect ratio, and must tell the model not to ask the user how many shots to use. The same figures must be used by the spec self-check, so a 15-second reply cut into only two shots must raise a density warning while a three-shot reply must not, and the warning must never fire for Seedance, whose shot blocks are counted inside its own single prompt.

- Compare node divider: with two images connected, moving the pointer onto the divider band must move the split left and right without holding any modifier key, and pressing the left button anywhere on the image must drag it too — in the node and in the fullscreen view alike. The handle pill on the divider must be grabbable rather than a painted decoration. Opening the fullscreen compare and clicking the ✕ must close it, and no other antd modal opened from inside the canvas may have its close button swallowed by canvas panning.

- Canvas thumbnail cache: an image node must render a downscaled webp instead of the full-resolution source while the node occupies at most 1024 device pixels on screen, and must fall back to the original as soon as zooming pushes it past that. Opening a canvas with roughly 50 large images must feel clearly faster on the second visit than on the first, because the thumbnails come back from IndexedDB instead of being re-encoded. Thumbnails must never leak into downloads, exports, saved collages, or anything sent to a model. The cache must stay bounded: entries untouched for 30 days are dropped, and the store is trimmed back to 400 entries / 80 MB in least-recently-used order. A remote image that taints the canvas must silently fall back to the original rather than showing a broken image.

- ComfyUI local runtime summary: once ComfyUI is running, the environment panel must show the local GPU with its free and total VRAM, plus a count of locally installed models grouped as Checkpoints, diffusion models, text encoders, VAE, and LoRA. Both values come from ComfyUI's own `system_stats` and `object_info`, so they must stay empty while ComfyUI is not running and refresh after pressing the refresh button. A machine with no model files must show `No model files detected` instead of a row of zeros.

The loading stage must carry the hint that a first start or a node-heavy install makes this step the slowest. Connecting to a cloud ComfyUI must label the action as disconnecting rather than stopping, since no local process is involved.
