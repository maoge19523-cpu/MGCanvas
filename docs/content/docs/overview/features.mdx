# Features

## Canvas projects

- Create, rename, duplicate, delete, import, and export canvas projects.
- Persist projects in the browser and optionally synchronize them with WebDAV.
- Keep viewport, background, nodes, connections, and assistant sessions with each project.

## Canvas workspace

- Pan, zoom, reset the view, select multiple nodes, copy and paste, undo and redo.
- Drag files onto the canvas and use lines, dots, or a blank background.
- Export the entire canvas or selected elements with their resources.

## Nodes and workflows

- Text, image, video, and generation-configuration nodes.
- Connect text prompts and reference media to generation nodes.
- Generate or rewrite text, create images, edit images from references, and create videos.
- Preserve original image ratios by default and organize batch results as connected nodes.
- Record prompts, models, dimensions, quality, and references on generated nodes for retries.
- Compare two connected images inside the node with a draggable split divider, or open a full-screen compare view and nudge the divider with the arrow keys.
- Collage up to ten connected images as freely arranged layers: move, rotate, scale, stretch, and reorder them in a full-screen editor with undo and redo, then save the arrangement as one new image node. The layer layout stays on the node, so double-clicking it again resumes editing from where you left off.

## AI generation

- Connect to user-provided OpenAI-compatible endpoints directly from the browser.
- Configure multiple channels, fetch or enter model names, and choose default text, image, and video models.
- Support image count, aspect ratio, quality, transparent backgrounds, reasoning effort, and custom invocation scripts.
- Support OpenAI-style video endpoints and Volcengine Ark generation tasks.
- Image and video nodes can use configured channel models directly: the model list is filtered by node capability, and generation is routed by model source (channel protocol or built-in catalogue).
- Built-in call scripts are matched automatically by channel base URL (initially covering Alibaba Cloud Bailian image and video generation, including async task polling), so no script authoring is required.
- Channel models accept canvas parameters: image size and count, video resolution and duration.
- Channel models can drive audio nodes through the OpenAI speech shape (`{base}/audio/speech`), so text-to-speech providers such as Zhipu GLM-TTS (`glm-tts`) work directly. Voice, audio format, speed, and instructions are configured on the audio node itself — with a settings entry in the same row where image and video nodes show their parameters — and the node's values are what actually reaches the provider. A provider refusal is reported with the provider's own wording instead of being stored as an unplayable clip.

## AI director

- Turn a creative brief into production-ready shot prompts for MiniMax H3 or Seedance 2.0; the target model, generation mode, total duration, and aspect ratio are chosen in the panel.
- Reference images and audio are picked from the canvas (with candidates you enable explicitly) or uploaded, then mapped into the prompt as ordered labels or handles.
- MiniMax H3 covers text-to-video, image-to-video, first-frame/last-frame, and full-reference modes, and applies the matching alignment instruction on the first line.
- Seedance 2.0 output is a single structured Chinese prompt: the handle section only when reference images are supplied, the three ⚠️ warnings, 【镜头N】 blocks numbered from 1 without gaps, a style block, an ambience block, and a closing duration and aspect line.
- A spec self-check runs on the generated prompts and shows a verdict plus a per-shot list of issues covering H3 field names and order, unreplaced placeholders, timeline continuity and numbering across shots, speech rate against the official density rules, music concreteness, reference labels, and authoring-template leakage.
- Apply to canvas drops the whole storyboard into one text node and, when asked, wires it to a single video generation node.
- Generate the whole film creates that text node plus one video generation node and starts the generation, so the `[Shot 1]`/`[Shot 2]` … sequence inside the prompt produces the whole film in one call, after an explicit confirmation that it really spends quota.

## Video composition

- A composite node accepts multiple video nodes as segments, plus one audio node on the voice port and one on the music port.
- Each segment supports start/end trimming (clamped to the source duration), segment volume, and a transition into the next segment (cross dissolve, wipe left or slide up, 0.2–1.5s, capped at 80% of the shorter neighbour) — seams left on a hard cut keep the plain concatenation path.
- Each segment can carry one line of subtitles, burned in through FFmpeg's libass with the font named explicitly (Microsoft YaHei) so Chinese never renders as missing glyphs; font size and bottom margin scale with the output height, long lines wrap by themselves, and the layout can be bottom or centred.
- Voice and music are separate tracks with their own volume and fade-out, mixed together with the clips' own audio and volume-compensated so nothing gets quieter.
- Output options include resolution (long edge 1080/720/480, aspect follows the first segment), frame rate and global fade in/out.
- Composition runs through a locally installed FFmpeg (not bundled with the installer); common install locations are detected automatically and a manual path can be set in settings. Transitions and subtitles need FFmpeg 4.3 or newer with libass.
- There is no timeline UI; the node targets light editing such as concatenating generated clips with transitions, subtitles and separate voice and music tracks.

## MGCanvas Agent

- Connect local Codex through MGCanvas Agent and MCP without giving a web server direct access to browser state.
- Read the active canvas, selection, nodes, edges, generation status, and apply structured operations.
- Use Codex from the browser side panel with streaming responses, history, approvals, permissions, diagnostics, and local Skills.
- Isolate active canvases and turns across multiple browser tabs.

See [Codex App Plugin](/docs/overview/codex-app-plugin) for installation and usage.

## Skills and local memory

- **Install a skill from a link**: paste the URL of a `SKILL.md` into the Skill page to install it. The local Agent downloads and validates the document (follows redirects, 20-second timeout, 512KB cap; the parent directory name is used when the front matter has no `name`, and a missing `description` is refused with a reason). Only http/https links are accepted, and the usual skill naming rules still apply.
- **Install a skill from the open ecosystem**: search by keyword, review each result's name, source and install count, then install it. The Agent resolves the real `SKILL.md` path inside the matching repository and reuses the same download, validation and write path, so an installed skill can be edited, enabled, disabled and deleted like any other.
- **Skill resource files**: the "Files" entry on a managed skill row lists, creates, edits and deletes the extra files in that skill directory (notes, templates, examples). One file is capped at 512KB, at most 200 files and 4 levels deep; path traversal and symlinks are refused, and `SKILL.md` and `agents/openai.yaml` are not editable there because they keep their own revision check.
- **Local memory**: the Configuration page stores long-lived preferences in the local workspace only (one entry 2000 characters, 50 entries, 32KB in total; going over the limit is reported instead of being silently truncated). While the switch is on, the entries are attached to what is sent to the model on every message, and nothing is attached when it is off; the text you typed is never altered, and the preferences are expected to land in real node parameters — for example a default 16:9 frame ends up in the generation node's aspect ratio — rather than only being repeated back in the reply.

## Plugin system

Canvas plugins can contribute node types, rendering, inspectors, serialization, migration, toolbar actions, and optional AI generation capabilities. Built-in and local plugins are managed through the canvas UI.

## Prompts and assets

- Synchronize supported public prompt repositories and add custom standard JSON sources.
- Search across enabled sources, filter by tags, inspect prompt details, copy prompts, and insert them into the canvas.
- Store reusable images, videos, audio, and prompt assets in the browser.

## Configuration and synchronization

- Export and import channel, model, generation, prompt-source, and WebDAV settings.
- Store application data and API credentials locally in the browser.
- Use WebDAV for optional cross-device synchronization.

## Current limitations

- The project is frontend-first and does not provide built-in cloud accounts or cloud storage.
- API keys remain in browser storage and requests are sent directly to configured providers.
- Production Docker static-resource paths still require broader deployment verification.
